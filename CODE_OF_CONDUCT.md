# Code of conduct

## The short version

Be decent to each other. The directory is a list of things people made; treat the people who made
them, and the people reading, with ordinary respect.

## Expected

- Discuss the work, not the person. Technical criticism is welcome; contempt is not.
- Assume good faith. Ask a question before assuming a motive.
- Respect a maintainer's decision on scope. "Not this project" is a legitimate answer.
- Credit people. If someone's listing or code helped you, say so.

## Not acceptable

- Harassment, insults, or personal attacks in issues, pull requests or commit messages.
- Discriminatory language or imagery relating to gender, gender identity, sexual orientation, race,
  ethnicity, religion, disability, age or appearance.
- Sexual attention or advances of any kind.
- Publishing anyone's private information without permission.
- Using the issue tracker or pull requests to promote an app outside the normal submission flow.
- Sustained disruption: reopening settled threads, editing comments to change the record, badgering.

## Scope

Applies to issues, pull requests, commit messages, the listings themselves and any space where
someone is representing the project.

## Enforcement

Report anything uncomfortable to the maintainers at the address in `src/config.ts`, or flag it to a
maintainer directly. Reports are read privately.

Maintainers may, in proportion to the behaviour:

1. Ask for the behaviour to stop, with an explanation.
2. Remove the offending comment or listing and warn the account.
3. Block the account from the repository.

Decisions are made in good faith and explained to the person affected. If you think a decision was
wrong, say so once, calmly. That is not a violation; repeating it after the answer is.
